# Alert Investigation

## Objective

Investigate the security alerts generated by Wazuh after performing a File Integrity Monitoring (FIM) test.

---

# Incident Summary

During routine testing of the Wazuh SIEM environment, a file was intentionally created and modified inside a monitored directory to verify that File Integrity Monitoring was functioning correctly.

Wazuh successfully detected both events and generated alerts.

---

# Environment

| Component | Details |
|----------|----------|
| Wazuh Manager | Ubuntu Server 24.04 |
| Endpoint | Ubuntu Server Agent |
| Analyst Workstation | Kali Linux |
| SIEM | Wazuh 4.14.x |

---

# Trigger

The following commands were executed on the monitored endpoint.

Create file

```bash
sudo touch /etc/wazuh_test_file
```

Modify file

```bash
echo "Testing Wazuh FIM" | sudo tee /etc/wazuh_test_file
```

---

# Detection

The Wazuh Syscheck module monitored the `/etc` directory and detected:

- File creation
- File modification

Alerts appeared in the Wazuh Dashboard shortly after the activity occurred.

---

# Investigation Steps

The analyst performed the following actions:

1. Logged into the Wazuh Dashboard.
2. Opened **Security Events**.
3. Filtered recent alerts.
4. Located File Integrity Monitoring events.
5. Reviewed alert metadata.

---

# Evidence Collected

The alerts contained information such as:

- Event timestamp
- Agent name
- File path
- Rule description
- Severity level
- Decoder information

---

# Analysis

The detected activity matched the intentional administrative actions performed during testing.

No indicators of compromise (IoCs) were observed.

The generated alerts confirmed that:

- The Wazuh Agent was successfully reporting events.
- Syscheck was operating correctly.
- Alert forwarding to the Wazuh Manager was functional.
- The Dashboard was correctly displaying security events.

---

# Security Impact

Although the activity was legitimate, the same detection mechanism could identify:

- Unauthorized configuration changes
- Malware modifying system files
- Web shell deployment
- Privilege escalation attempts
- Insider threats

---

# Response

Since the activity was authorized, no containment or remediation actions were required.

The incident was classified as:

**Status:** Closed

**Severity:** Informational

---

# Lessons Learned

This exercise demonstrated the effectiveness of Wazuh File Integrity Monitoring for detecting changes to critical system files.

It also validated end-to-end communication between:

- Wazuh Agent
- Wazuh Manager
- Wazuh Dashboard
